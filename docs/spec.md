# 会社のキャッシュ増加シミュレーター 仕様書

## 目的

- 使う人: 保険・DCの提案者（実践会の会員）。顧客の社長との面談で、PCのブラウザから使う
- 何を見るか: 年間の法人利益から「何もしない」と「DC・保険・役員報酬減額を組み合わせる」を比べ、会社に残るお金（現金・法人保有保険）と、DC加入者（個人）の資産を分けて見る
- 提案者として、役員報酬が分からない顧客でも、利益だけ入れて対策前後の法人税と会社に残るお金を見せたい。なぜなら、多くの提案者は利益しか聞けていないから
- 提案者として、保険を「期間末まで払う」と「5年・10年で払済」の差を並べて見せたい。なぜなら、短く払って長く置く効果を顧客が判断しやすいから
- 提案者として、保険が全額経費にならないぶん法人税が出ていくことも見せたい。なぜなら、出ていくお金を正しく伝えないと提案の信頼を失うから
- 提案者として、DC資産は会社のお金ではないと分かる形で見せたい。なぜなら、法人の現金と混同させてはいけないから

## やること（MVP）

- 条件を入れると、対策なし／対策あり（通常・払済1・払済2）をすぐに計算して並べ、払済と通常の差も出す
- 入力: 基本条件・企業型DC・福利厚生保険・役員保険・払済ケース・役員報酬減額（任意）
- 表示の順: 結論と概要 → 期間末の資産のグラフ → 法人の現金の推移のグラフ → 比較表 → 年次の明細 → 計算の根拠
- 法人の現金・法人保有保険・DC加入者資産を、色と「法人／個人」の位置で分けて表示する
- 未確定の値（返戻率・損金割合・DC掛金・税率）は入力にし、「概算」「保証ではない」と表示する
- マイナスの利益・現金不足・払込過大などで注意を出す
- デモ用の仮データ・全項目リセット・印刷（A4横4ページの提案資料の形）
- 参考総額（法人保有＋DC加入者資産）は、帰属が違う合計だと明記したうえで、選んだときだけ出す

## やらないこと

- 退職金の支給とその税金、保険の解約益にかかる法人税、DCの受け取り時の税金
- 役員個人の所得税・住民税・手取りの変化（今回は作らない）
- 目標額（例: 2億円）からの逆算
- 保険の途中の年の解約返戻金（設計書の年別の返戻率が入力されていないため推測しない）
- 年ごとに違う利益の入力・人数ごとに違うDC掛金・給与から振り替えるDC（今回は作らない）
- 会員認証・パスワード・公開・FANTSとの連携・入力内容の保存
- CSVの保存・損金割合や比較期間の候補ボタン（今回は作らない）
- 保険ごとに違う払済年数・評価する年の選択・期首の現金残高の入力（今回は作らない）

## 扱うデータ

| 項目名 | 種類 | 必須かどうか |
|---|---|---|
| 基本条件: 法人名・年間法人利益（万円）・比較期間（年）・法人実効税率（%） | 文字・数値 | 法人名は空欄可（50文字まで）。ほかは必須 |
| 企業型DC: 加入人数・1人あたり月額掛金（円）・運用年率（%）・拠出期間（年） | 数値 | 人数・年率は必須。掛金は人数1人以上で必須。拠出期間は空欄可 |
| 保険（福利厚生・役員それぞれ）: 使う／使わない・年間保険料（万円）・損金割合（%） | 選択・数値 | 使うときは必須 |
| 保険の返戻率: 通常・払済1・払済2 の比較期間末の返戻率（%） | 数値 | 任意（空欄は解約返戻金を計算しない） |
| 払済ケース: 払込年数1・2（年） | 数値 | 保険を使うときは必須 |
| 役員報酬減額: する／しない・人数・1人あたり月額（円）または年間総額（万円） | 選択・数値 | するときは必須 |
| 社会保険料の減少（任意）: 減額前の報酬月額（円）・年齢・都道府県 | 数値・選択 | 任意（報酬月額を入れたら年齢・都道府県が必須） |

## 画面一覧と遷移

- 画面は1枚（比較画面）。画面の移動はない
- 左: 条件入力（基本条件／企業型DC／福利厚生保険／役員保険／払済ケース／役員報酬減額）
- 右: 結論と概要（対策なし・通常・払済1・払済2）→ 資産のグラフ → 現金の推移のグラフ → 比較表 → 年次の明細 → 計算の根拠 → 注意・前提
- 上のボタン: デモ用の仮データを入れる／全項目リセット／印刷する
- 入力を変えると、ボタンを押さなくても右側がすぐ変わる
- 印刷すると、画面ではなく A4横4ページの提案資料の形（法人名・作成日つき）で出る

## 使う技術

- 画面: React + TypeScript（元の「役員報酬・退職金 比較シミュレーター」と同じ構成。デザインと社会保険料の計算をそのまま引き継ぐため）
- 保存の仕組み: なし（入力は保存しない。計算はブラウザの中だけで行い、外部に送らない）
- 動かし方: ターミナルで `npm run dev` → ブラウザで http://localhost:5173 。確認用モックは `mock/index.html` をダブルクリック
