# 動きの一覧

`docs/spec.md` と今の画面から作った、画面の動きの一覧。補修のため、作ったあとで書いている（状態はすべて「作った」）。
「確かめた結果」は、自分の手で試してから書く（OK／NG と、NG なら何をして何が起きたか）。

開き方: ターミナルで `corporate-cash-simulator` フォルダに移り `npm run dev` → ブラウザで http://localhost:5173 を開く。
各行は、ページを再読み込み（⌘R）して入力が空の状態から始める。「基本の条件」は、年間法人利益 3000・比較期間 20・法人実効税率 30（20 と 30 は最初から入っている）。
