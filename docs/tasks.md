# 作る順番

`docs/spec.md` をもとにした作る順番。実際に作った順に並べ直した（補修のため、作ったあとで書いている）。
印 `- [x]` は「作って、自動テストと画面で確かめた」もの。自分の手での確かめは 9 で行う。

## 必須

- [x] 1. 比較画面の骨組みを出す（左に条件入力の6つのまとまり、右に結果の場所）
  - 終わったと言える条件: ブラウザで開くと、左に「基本条件〜役員報酬減額」の見出し、右に結果の場所が出る
  - なぜ先か: 以降のタスクはすべてこの画面の上で確かめるため
- [x] 2. 基本条件だけで「対策なし」を計算して出す
  - 終わったと言える条件: 利益3,000万円・20年・30%で、法人税の累計1億8,000万円・現金4億2,000万円が出る
  - なぜ先か: 対策ありはすべて、この「対策なし」との差で見せるため
- [x] 3. 企業型DCを加え、DC加入者資産を法人のお金と分けて出す
  - 終わったと言える条件: 2名・62,000円・20年・6%で、DC加入者資産が約5,623万円と出て、法人の現金には入らない
  - なぜ先か: 保険より計算が単純（全額が会社の費用か0円か）で、法人／個人を分ける表示の土台になるため
- [x] 4. 福利厚生保険・役員保険（期間末まで払う通常ケース）を加える
  - 終わったと言える条件: 損金割合を0%と50%にすると法人税は変わり、払う保険料は同じ
  - なぜ先か: 払済ケースは、この通常ケースの払い方を途中で止めるだけなので
- [x] 5. 払済ケース（払済1・払済2）を並べ、通常との差を出す
  - 終わったと言える条件: 5年払済で6年目以降の保険料が0円になり、期間末の返戻率で解約返戻金が出る
  - なぜ先か: 打ち合わせでいちばん見せたいと言われた比較のため
- [x] 6. 役員報酬の減額（任意）を加える
  - 終わったと言える条件: 減額分が課税対象利益と現金に足され、保険料は自動で増えない
  - なぜ先か: 任意の項目なので、ほかの対策ができてから足す
- [x] 7. 入力のチェックと注意を出す
  - 終わったと言える条件: 必須の欄が空・範囲外でエラーが出て、利益がマイナスのとき注意が出る
  - なぜ先か: 計算がそろってから、まとめて決まりを当てるため
- [x] 8. 資産のグラフ・現金の推移のグラフ・比較表・年次の明細・計算の根拠を出す
  - 終わったと言える条件: 法人の現金・法人保有保険・DC加入者資産が、色と「法人／個人」の位置で分かれて見える
  - なぜ先か: 表示の部品は、計算の結果がそろってから作るため
- [x] 9. 動きの一覧 `docs/actions.md` を作り、自分の手で全部確かめる
  - 終わったと言える条件: `docs/actions.md` の全行の「確かめた結果」が OK（NG は理由つき）
  - なぜ先か: 作ったものを、AI ではなく自分の手で確かめて初めて「できた」と言えるため

## 余裕があれば

- [x] 10. デモ用の仮データ・全項目リセット・印刷（提案資料の形。CSVは外した：決定C14）
  - 終わったと言える条件: デモを押すと仮データが入り、リセットで空に戻り、印刷するとA4横4ページの提案資料の形（法人名・作成日つき）で出る
  - なぜ後か: 計算と表示ができていれば、なくても1回は使えるため
