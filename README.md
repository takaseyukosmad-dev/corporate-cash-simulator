# 会社のキャッシュ増加シミュレーター

年間の法人利益から、「何もしない」場合と「企業型DC・福利厚生保険・役員保険・役員報酬の減額」を組み合わせた場合を比べ、
法人の現金・法人保有保険の解約返戻金・DC加入者（個人）の資産を分けて表示するWebアプリ。
保険は「通常（期間末まで払込）」と「払済（例: 5年・10年）」を並べて比べられる。

サーバーを持たない静的Webアプリ（React + TypeScript + Vite）。入力内容は保存せず、計算はブラウザ内で行う。
デザインと社会保険料の計算は「役員報酬・退職金 比較シミュレーター」から引き継いでいる（そちらのアプリは変更していない）。

## 使い方（開発）

必要なもの: Node.js 24 以上

```bash
npm install      # 最初に1回
npm run dev      # 開発用サーバー → http://localhost:5173 を開く
npm test         # テスト（要件定義6章の受け入れテストを含む）
npm run build    # 型チェックと公開用ファイルの作成（dist/）
npm run lint     # コードのチェック
npm run mock     # 確認用モック（mock/index.html）を作り直す
```

`mock/index.html` は、実際の画面の部品にデモ用の仮データを入れて作った確認用のHTML。サーバーなしでブラウザで開ける（入力欄は動かない）。画面を変えたら `npm run mock` で作り直す。

## 印刷（提案資料）

画面で条件を入れて「印刷する」を押すと、ブラウザの印刷画面が開き、A4横4ページの提案資料の形で出る。
元のアプリ（役員報酬・退職金 比較シミュレーター）の提案資料PDFを参考にしている（決定C14）。

| ページ | 中身 |
|---|---|
| 1 | タイトル（法人名・作成日）・ご提案の目的・考え方・比較するケース・お金の流れ |
| 2 | 比較結果の要約・概要・期間末の資産のグラフ・法人の現金の推移のグラフ |
| 3 | 比較表 |
| 4 | 比較条件・計算の根拠・注意・計算の前提・ご注意 |

- 法人名を入れると、1ページ目のタイトルが「○○様　会社のキャッシュ増加のご提案」になる（空欄なら「様」は付かない）
- 作成日は印刷した日
- 比較表で「参考総額も表示する」にチェックを入れていると、印刷にも出る
- 年次の明細は印刷に入らない（画面で見る）
- 入力にエラーがあるときは「印刷する」を押せない
- 色が出ないとき（Chrome）: 印刷画面の「詳細設定」で「背景のグラフィック」をオンにする
- PDFにしたいとき: 印刷画面の送信先で「PDFに保存」を選ぶ

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `src/calc/fundFormation/` | 比較の計算（画面のコードを含めない） |
| `src/calc/tax/`・`src/data/` | 社会保険料の計算と料率（令和8年度。役員報酬の減額で会社負担が減る分に使う） |
| `src/screens/` | 画面（入力・結果・グラフ・印刷用の表示） |
| `src/shared/` | 表示の書式・グラフの目盛りなど |
| `tests/` | テスト |
| `mock/` | 確認用モック（`npm run mock` で作る） |
| `scripts/` | モックを作るスクリプト |

## 計算していないこと

退職金の支給とその税金、保険の解約益にかかる法人税、DCの受け取り時の税金、役員個人の所得税・住民税の変化。
税額・損金算入はすべて概算で、返戻率・運用利回りは入力された仮定（保証された値ではない）。
